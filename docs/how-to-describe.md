# كيف تطلب رسمة

## الفكرة

الوصف منفصل عن الكود. أنت تصف بالعربية، وأنا (Claude) أستخرج المعاملات وأكتبها في
ملف مشهد، والكود العام ينفّذ الرسم على خوادم GitHub.

```
وصفك بالعربية  →  Claude يستخرج المعاملات  →  scenes/*.yaml  →  GitHub Actions  →  renders/*.png
```

لا يُستدعى أي نموذج ذكاء اصطناعي أثناء التشغيل: بعد كتابة ملف المشهد يصبح الرسم
حسابياً بحتاً، فالنتيجة ثابتة ومجانية.

## الطريقة

1. **اكتب الوصف** — في المحادثة مباشرة، أو أضف ملفاً في `descriptions/`.
2. **أترجمه** إلى `scenes/<اسم>.yaml`.
3. **ادفع التغيير** — الـ workflow يرسم ويحفظ الناتج في `renders/` تلقائياً.

## ما الذي يفيد ذكره في الوصف

| اذكر | مثال |
|---|---|
| العناصر ومواضعها النسبية | «مصباح على يمين الوسادة، نبتة بجانبه» |
| الألوان | «ثعلب برتقالي، وسادة حمراء، كوب أزرق» |
| الأحجام النسبية | «الرأس أكبر قليلاً من الجسم» |
| الخلفية | «بيضاء» أو «سماء ليلية متدرّجة» |
| الأسلوب | «خطوط سميكة، أسلوب كرتوني للأطفال» |
| النوع المطلوب | «ملوّنة» أو «خطوط للتلوين» أو «الاثنتان» |

كلما كان الوصف أدقّ في المواضع والألوان، قلّت جولات التعديل.

## بعد أول نتيجة

قل ما تريد تغييره بلغة طبيعية: «كبّر العينين»، «حرّك الذيل للأعلى»، «اجعل الوسادة
زرقاء». كل هذه تعديلات على أرقام داخل ملف المشهد، لا على الكود.

## ما يستطيعه النظام اليوم

**أشكال أولية:** دائرة · بيضاوي · مستطيل · مضلع · نجمة · كتلة عضوية · مسار SVG خام
· خط · نص

**عناصر مركّبة:** كائن (`creature` — يغطي الثعلب والقطة والأرنب والدبّ بتغيير
المعاملات) · مصباح · نبتة · وسادة · كتاب · كوب · شجرة · سحابة · شمس أو هلال · بيت

**أدوات تركيب:** مجموعة · تكرار (على خط، أو شبكة، أو نثر ببذرة ثابتة)

**ألوان:** لون واحد أو تدرّج لوني، وأسماء ألوان قابلة لإعادة الاستخدام

## حدوده

- ليس مولّد صور: لا يرسم إلا ما في مفردات العناصر أعلاه. ما ينقص أضيفه كعنصر جديد
  في `drawlib/elements.py` عند الطلب.
- المنظور بسيط: ترتيب الطبقات فقط، بلا عمق حقيقي ولا ظلال.
- النص العربي داخل الرسمة قد لا يُشكَّل بشكل صحيح عند تحويل SVG إلى PNG. النص
  اللاتيني يعمل بلا مشاكل.
