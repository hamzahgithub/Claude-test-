## بنية النظام باختصار

- **عقدة الحساس** (أعلى الخزان): حساس راداري + متحكم منخفض الاستهلاك + وحدة راديو + بطارية ولوح شمسي، داخل علبة محكمة.
- **وحدة المتحكم والعرض**: وحدة راديو + متحكم + شاشة + مخرج ريلاي للمضخة + تغذية.
- **الربط بينهما لاسلكي** (لا يوجد سلك بيانات بين العقدتين).
- حساب المستوى: `h = H_total − d` حيث `d` المسافة المقيسة من الحساس إلى سطح الماء.

## حدود هذا التصميم

هذا **تصميم مبدئي** يحتاج تحققًا هندسيًا واختبارًا ميدانيًا. لا يتضمن أرقام قطع ولا موديلات ولا أرقامًا مؤكدة للمدى أو الدقة أو الاستهلاك؛ كل قطعة تُختار فعليًا يجب التحقق من ورقة بياناتها الرسمية. كما أن تخصيص الترددات اللاسلكية وحدود قدرة الإرسال تختلف حسب الدولة وتلزم مراجعة الجهة التنظيمية المحلية.
